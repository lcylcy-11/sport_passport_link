# 홈 화면 검토 안내

화이트·그레이 유리 질감의 홈 화면과 프로필/콩 성장 카드 변경입니다. 검토 대상은 홈 화면이며 다른 메뉴 화면의 디자인과 기존 계정·운동 기록 모델은 유지합니다.

## 주요 변경

- 프로필에 주활동 지역, 연령대, 매너지수를 표시하고 종목별 기록을 독립된 흰 패널로 정리했습니다. TENNIS/FUTSAL/RUNNING 제목에만 채도를 낮춘 노랑/초록/파랑을 사용합니다.
- 매칭 찾기·자리 만들기를 프로필 아래에 배치했습니다. 오늘의 한 줄·근처 자리 대신 오늘 일정과 그룹·랭킹 바로가기를 표시합니다.
- 프로필 카드를 위아래로 뒤집으면 중앙 콩, 왼쪽 위 닉네임, 오른쪽 위 장비 3개와 오른쪽 아래 최근 30일 운동 횟수를 확인합니다. 앞뒤 크기는 같고 아래 버튼 위치도 유지됩니다.
- 원형 프로필 이미지를 사진 또는 콩으로 선택하고 콩 닉네임을 수정할 수 있습니다. 사진은 기존 프로필 저장 명령을 사용하고, 표시 선택·콩 닉네임은 현재 계정별 브라우저 설정입니다.
- 모바일 안전 영역, 하단 메뉴 여백, 터치 영역을 조정했습니다. 402×874는 브라우저 미리보기 기준이며 실제 iPhone/Safari 검증은 별도로 필요합니다.

## 로컬 확인

Node.js 24를 사용합니다. 처음 받는 환경에서는 루트 README의 로컬 계정·DB 설정을 따르고, 기존 환경의 데이터는 그대로 사용합니다.

```powershell
npm ci
npm start
```

`http://127.0.0.1:4174/#/home`에 로그인한 뒤 다음을 확인합니다.

1. 카드의 빈 영역 또는 ‘콩 성장 보기’를 눌러 앞뒤 카드 크기와 아래 버튼 위치가 유지되는지 확인합니다.
2. 콩 닉네임 연필, 프로필 사진/콩 선택, ‘프로필에서 자세히 보기’를 확인합니다.
3. 매칭·자리 만들기·그룹·랭킹 이동과 오늘 일정 표시를 확인합니다.
4. 모바일 320/390/402px와 데스크톱에서 가로 넘침과 글자 겹침을 확인합니다.

최종 코드에서 `npm run check`(30개 테스트, 구문·타입·빌드), `npm run test:e2e`(2개 브라우저 여정), `npm run test:build`가 통과했습니다.

프로필 정보가 담긴 로컬 화면 이미지는 공개 저장소에 포함하지 않습니다. 본인의 로컬 계정 또는 테스트 계정으로 화면을 확인합니다. 코드와 생성한 임시 콩 이미지에는 실행 중인 사용자의 계정·운동 기록을 포함하지 않습니다.

## 팀원 콩 구현과 합칠 부분

실제 성장 로직을 중복 구현하지 않았습니다. 현재 장비 레벨은 ‘준비 중’이고, 최근 운동 횟수만 완료 결과의 실제 참석 기록으로 집계합니다. [HOME-KONG-INTEGRATION.md](../../HOME-KONG-INTEGRATION.md)의 `registerHomeCharacterProvider` 계약에 최종 이미지·닉네임·장비 레벨을 연결합니다. 공용 닉네임/아바타 저장 필드가 준비되면 문서에 표시한 브라우저 설정 함수를 교체합니다.

팀장 검토 후 이 브랜치를 `main`에 병합해 적용할 수 있습니다. 이 PR 자체로 배포하거나 `main`을 변경하지 않습니다.
