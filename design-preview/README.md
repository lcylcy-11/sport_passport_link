
# DWNC 디자인 시안 3종

이 폴더는 멀티 스포츠 프로필·매칭 플랫폼의 **홈 화면 방향을 고르기 위한 로컬 초안**입니다. 같은 가상 사용자와 운동 정보를 세 가지 다른 화면 구성으로 보여줍니다.

- **A · 필드 노트:** 밝은 녹색, 오늘의 활동과 가까운 매칭 중심
- **B · 플레이북:** 어두운 경기장 분위기, 기록과 경기 중심
- **C · 블루아워:** 차분한 파란색, 일정과 파트너 중심

## 실행

Node.js가 설치된 환경에서 이 폴더를 작업 디렉터리로 열고 `npm start`를 실행합니다. 서버는 `127.0.0.1:4173`에만 바인딩됩니다.

직접 열기: [A](http://127.0.0.1:4173/#a) · [B](http://127.0.0.1:4173/#b) · [C](http://127.0.0.1:4173/#c)

상단 A/B/C 탭은 클릭하거나 좌우 방향키로 전환할 수 있습니다. `모바일 미리보기` 버튼은 같은 페이지를 430px 너비로 보여줍니다. 실제 모바일 화면에서도 반응형 배치가 적용됩니다.

## 확인

- `npm run check`: 서버와 화면 스크립트의 JavaScript 문법 검사
- 브라우저에서 `/#a`, `/#b`, `/#c`를 직접 열어 화면과 탭 전환 확인
- 데스크톱과 모바일 너비에서 주요 콘텐츠가 잘리지 않는지 확인

화면 안의 운동 정보, 인물, 기록은 예시입니다. 콘텐츠 안의 버튼과 메뉴는 시각 검토용이며, **시안 전환과 모바일 너비 전환만 동작**합니다. 로그인, 매칭 신청, 데이터 저장, 외부 통신은 구현하지 않았습니다. 실제 플랫폼 기능은 사용자가 디자인 방향을 고른 뒤 별도 작업으로 진행합니다.
