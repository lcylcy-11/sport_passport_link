# DWNC 로컬 데모

DWNC는 테니스·풋살·러닝의 프로필, 매칭, 친구, 그룹, 운동 기록을 한 흐름으로 체험하는 **브라우저 안의 데모**입니다. 사용자가 고른 A 시안의 밝은 녹색 화면을 바탕으로 만들었습니다.

## 실행과 확인

Node.js 24 환경에서 저장소 루트에서 `npm start`를 실행한 뒤 [로컬 앱](http://127.0.0.1:4174/#/home)을 엽니다. 서버는 `127.0.0.1`에만 바인딩됩니다. `npm test`는 도메인 규칙과 이전 데이터 보존을 검증하고, `npm run check`는 문법 검사와 테스트를 실행합니다. 외부 패키지 설치는 필요하지 않습니다.

## 주요 흐름

1. 상단에서 가상 사용자를 바꾸거나 **친구와 사람들 → 새 데모 사용자**로 새 인물을 만듭니다. 새 인물은 바로 프로필 화면으로 이동해 종목별 정보를 채울 수 있습니다. 프로필 아이콘 또는 기기의 PNG/JPEG/WebP 사진을 사용할 수 있습니다. 사진은 180×180 JPEG로 축소해 로컬에 저장합니다.
2. **매칭 찾기**에서 종목, 방식, 지역, 장소, 날짜, 시간대, 빈자리 등으로 찾고 신청합니다. 모집자는 **내 운동 → 상세 보기**에서 신청자의 프로필을 보고 수락·거절합니다. 참석자가 확정되면 일정에 나타납니다.
3. 친구 코드를 통해 신청·수락한 뒤, 친구 프로필에서 내가 모집한 운동에 초대할 수 있습니다. 초대를 수락하면 일정에 바로 등록됩니다. 그룹은 만들기·가입하기가 가능하며, 멤버만 그룹 전용 운동 자리와 일정을 봅니다.
4. 확정된 운동의 상세 화면에서 참석자와 결과를 한 번 기록합니다. 프로필의 종목별 통계, 오늘 운동, 지역·장소·기간별 랭킹과 그룹 기록에 반영됩니다. 참석자끼리는 각 한 번씩 매너 평가를 남길 수 있습니다.
5. 홈에서 오늘의 한 줄을 저장하고 **오늘 운동 카드 미리보기 · PNG**를 누르면 이미지와 다운로드 링크가 나타납니다. 프로필 카드도 내려받을 수 있습니다.

테니스는 단식 2인 또는 복식 4인으로 진행하며, 두 팀과 스코어로 승패를 계산합니다. 참석 인원이 부족하면 경기 미성립으로 남기고 승패에는 넣지 않습니다. 풋살 모집 참가자는 같은 팀입니다. 팀 스코어로 승·무·패를 계산하고 실제 참석자 중 MVP와 각자 포지션을 기록합니다. 러닝은 참석자마다 거리·페이스·후기를 기록하고, 평균 페이스는 거리로 가중합니다. 불참자는 기록·MVP·매너 평가 대상에서 제외됩니다. 결과는 운동 자리당 한 번만 저장됩니다. 데모에서는 시연을 위해 날짜가 지나기 전에도 확정된 운동의 결과를 입력할 수 있습니다.

랭킹은 이번 달(선택 월) 또는 전체 기간의 **실제 참석 기록이 있는 사용자**만 보여줍니다. 그룹 풋살 팀 승률은 경기 한 건을 한 번만 세며, 그룹 테니스는 멤버 간 내부 경기로 따로 표시합니다. 매너 지수는 기존 예시 기준값을 5회분으로 두고 새 동료 평가를 합산한 평균입니다. 모집자는 완료 전 자리를 취소할 수 있고 신청자는 완료 전 신청·참가를 철회할 수 있습니다. 알림은 앱 안에서만 제공됩니다.

## 저장과 범위

사용자 전환과 새 사용자 만들기는 실제 회원가입·로그인·권한 인증이 아닙니다. 모든 인물은 가상 예시이며, 상태와 축소된 사진은 이 브라우저의 `localStorage`에만 저장됩니다. 친구·그룹 공개 범위는 앱 화면과 데이터 규칙에 적용되지만, 같은 기기의 저장 데이터에 대한 실제 비밀 보관 기능은 아닙니다. 다른 탭에서 값이 변경되면 현재 탭의 편집을 멈추고 다시 불러오도록 안내합니다. 브라우저 저장을 사용할 수 없으면 변경은 현재 탭에만 유지된다고 표시합니다.

이전 버전의 수정된 데모 데이터는 같은 저장 키에서 검증 후 이전합니다. 데이터가 손상됐으면 자동으로 지우지 않고 복구 화면을 표시합니다. **예시 데이터로 다시 시작**을 선택하면 기존 로컬 데모 데이터가 제거됩니다.

실제 계정, 서버 저장, 지도, 외부 API, 자동 게시·공개 배포는 포함되지 않습니다. 이전 A/B/C 화면 시안은 [design-preview/README.md](design-preview/README.md)에 보존돼 있습니다.
