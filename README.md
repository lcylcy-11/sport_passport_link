# DWNC 로컬 데모

DWNC는 여러 종목의 프로필, 운동 상대 찾기, 참여 신청, 결과 기록을 한 흐름으로 살펴보는 **브라우저 안의 데모**입니다. 사용자가 고른 A 시안의 밝은 녹색 화면을 바탕으로 만들었습니다.

## 실행과 확인

Node.js 24가 설치된 환경에서 저장소 루트에서 다음을 실행합니다.

```powershell
npm start
```

앱: [http://127.0.0.1:4174/#/home](http://127.0.0.1:4174/#/home). 서버는 `127.0.0.1`에만 바인딩됩니다. `npm test`는 데이터 규칙을 검증하고, `npm run check`는 JavaScript 문법 검사와 테스트를 실행합니다. 별도 패키지 설치는 필요하지 않습니다.

## 데모 흐름

1. 상단 선택 메뉴에서 **김민서**를 고른 채 매칭 찾기로 이동합니다. 관악구의 오늘 저녁 테니스 자리를 필터로 찾아 신청할 수 있습니다. 이미 확정된 별도의 오늘 테니스 일정도 있습니다.
2. 다른 사용자로 전환해 자리를 만들거나, 모집자로 전환해 **내 운동 → 상세 보기**에서 신청자의 프로필을 보고 수락·거절합니다.
3. 확정된 참가자는 내 운동 일정에 나타납니다. 상세 화면에서 **데모 결과 입력**을 눌러 종목별 결과를 한 번 기록합니다.
4. 프로필의 종목 기록, 오늘 운동, 지역·장소 랭킹에 반영된 값을 확인합니다. 새로고침 뒤에도 같은 브라우저에서는 유지됩니다.

사용자 전환은 실제 로그인이나 권한 확인이 아닙니다. 모든 사용자는 가상의 예시 인물이며, 상태는 이 브라우저의 `localStorage`에만 저장됩니다. 다른 브라우저나 기기와 공유되지 않습니다. 저장이 불가능하면 화면에 현재 탭에서만 유지된다고 알립니다. 저장 데이터가 손상됐으면 복구 화면에서 예시 데이터를 다시 시작할 수 있습니다. 복구는 기존 로컬 데모 데이터를 지웁니다.

테니스는 **단식 2인**이며 승자 한 명을 입력하면 상대에게 패배가 반영됩니다. 풋살 모집 참가자는 **같은 팀**이고, 우리 팀과 상대 팀의 스코어로 승·무·패를 함께 기록하며 참가자 중 MVP를 고릅니다. 러닝은 참가자마다 거리와 페이스를 기록하고, 평균 페이스는 거리로 가중해 계산합니다. 결과는 운동 자리당 한 번만 저장됩니다. 데모에서는 시연 흐름을 위해 확정된 운동의 결과를 일정 날짜가 지나기 전에도 입력할 수 있습니다. 랭킹은 선택한 지역 또는 장소의 실제 결과가 있는 사용자만 표시합니다.

그룹, 친구, 지도, 외부 API, 실제 계정과 서버 저장, 공개 배포는 이 로컬 MVP 범위에 포함되지 않습니다. 이전 A/B/C 화면 시안은 [design-preview/README.md](design-preview/README.md)에 별도로 보존돼 있습니다.
